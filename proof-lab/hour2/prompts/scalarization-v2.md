Target: exact scalarization of a total two-output NAND minimization problem with one known one-gate component. This is a concrete bridge question. P versus NP remains unsolved, and solving this bridge alone would not settle it. All model proposals remain UNVERIFIED until independently checked.

MODEL AND INPUT. A circuit is a finite acyclic DAG of two-input NAND gates. Fanins may repeat, fanout is free, every gate costs one, inputs and output selectors cost zero, and there are no free constants or negations. Let n>=1, N=2^n. The Boolean function f is supplied by its complete N-bit truth table, and 0<=i,j<n, including i=j. Set g(x)=NAND(x_i,x_j). Let C(f) be ordinary single-output minimum NAND cost and J(f,g) the minimum number of gates in one shared DAG whose two selected outputs are f and g.

EXACT BRIDGE TO AUDIT FIRST. Define e(f,g) as the minimum gate count of an (n+1)-input circuit G(x,z) with G(x,g(x))=f(x) on every original input. Then J(f,g)=e(f,g)+1. For the upper bound, compute g once and then run G. For the lower bound, any DAG outputting g must designate a gate, since on the all-ones input g=0 but every input projection is1. Replace every use of that gate by the new free primary input z, delete the gate and renumber remaining wires, retaining sharing. On z=g(x) the remaining f-output is unchanged, with one fewer gate. If f used the same output gate, its replacement output is simply z. No assumption about the gate being first or having a minimal internal implementation is needed.

Also C(f)<=J(f,g)<=C(f)+1. Thus e(f,g) is either C(f)-1 or C(f), intersected with the nonnegative integers. The missing information is exactly whether an optimal f-DAG can also supply g as a wire. Knowing only the numeric value C(f) does not supply that incidence information without an additional proved reduction.

ONE REQUEST. Construct an explicit uniform deterministic polynomial-time reduction deciding J(f,g)<=s using ONLY an oracle for ordinary single-output total NAND-MCSP. Prefer a many-one scalarization (f,i,j,s)->(H,kappa); a genuinely exact polynomial-query Turing reduction is also meaningful if a many-one construction fails. Every query must be a completely specified truth table, with exact threshold and all gate costs accounted for. No partial truth tables, multioutput oracle, SAT oracle, circuit witnesses from the decision oracle, or unproved search-to-decision assumption are available.

QUANTIFIERS AND BIT COST. There must be one fixed constant c and one algorithm, independent of n,f,s. With L=N+ceil(log2(s+2))+O(log(n+2)), total classical bit computation, number of queries, and total query bits written must all be at most L^c. Each query table has 2^k bits<=L^c and its binary threshold has length<=L^c. Thus k=O(log L). An unbounded circuit prefix cannot be encoded by simply adding one truth-table dimension per gate. Size thresholds may be clipped using the explicit universal bound B(n)=3+(3n+7)2^n, since J<=B(n)+1. The required equivalence is exact for EVERY input, including zero-size projections, constants computed with paid gates, repeated fanins, f=g, and all threshold boundary cases. A same-threshold or shifted-threshold interval is insufficient.

SPECIFIC NEW ANGLE. Treat the pair (f,g) as a total shared-DAG problem. Seek a scalar gadget whose low-cost circuits can be decoded into a two-output DAG with the exact required budget. Any forced-gate, selector, replication or amplification argument must prove its LOWER bound against arbitrary shared circuits, rather than assume a direct-sum law. A constant-factor approximation does not resolve the one-gate ambiguity.

THE ORDINARY MUX IS NOT AN EXACT OFFSET REDUCTION. For H(x,b)=f(x) when b=0 and g(x) when b=1, there is no universal additive overhead even at n=1: when f=g=NOT x, J=1 and H=NOT x costs1 (gap0); when f=x and g=NOT x, J=1 but H=x XOR b has NAND minimum4 (gap3). Audit these exact small claims before using them. An offset may not be silently selected using the unknown optimum. This does not refute other global gadgets or an adaptive reduction.

PRIOR FAILED SHORTCUTS. Fixed pointwise completions depending only on (f(x),g(x),z) fail already at residual budget0. Zero-fill can reject all first-pair residual queries for AND2 despite its two-gate circuit. Ignore-fill and additive upper/lower intervals do not provide exact decision. An infinite cheaper-parity-phase construction shows optimal residual extensions can require every original coordinate and z, leaving 2^n holes. An automatic small-hole optimal-support promise is false. Do not recycle these assumptions or treat graph-relative support as total semantic independence.

A positive answer supplies the actual uniform reduction/gadget, table-generation algorithm, explicit fixed polynomial bounds, and both correctness directions with exact NAND counts. If a candidate is false, provide an exact counterexample and rigorously verified costs for that candidate. A finite counterexample to one gadget is not a proof that every reduction is impossible. If unresolved, identify the first precise new lemma and its quantifiers, rather than assume the desired scalarization. Distinguish mathematical proof from experiments. Do not claim circuit lower bounds or P!=NP from this bridge alone.
